机制与判定

原计划保留 R37 补偿。静止释放组在参考轨迹保持的 15.2–18.7 秒将机械臂指令和补偿清零，手指继续按原计划张开。反馈组再于 18.7 秒检查桌面支撑、物体稳定、手指实际张开及双手脱离，连续 6 个状态合格后允许退离；等待超过 2 秒则中止。退离中的接触或物体高速持续 3 个状态也触发中止。

停止新指令后，机械臂仍可能因已有目标和物理惯性运动。后续接触停止是碰后反应，并非预测避碰。三个条件使用同一安全模型、限位、物理参数、手指事件和任务门槛。

原任务门槛：末态 XY≤80mm，倾斜≤10°，曾抬升>50mm，末态高度变化在(-6,+12)mm内，原安全球违规与重置均为0。新增“合格完成”还要求参考轨迹完整执行且未中止。

公共执行方式统一更新：每步按当前权威相位重新计算指令，30秒共同观察期，12个环境/组；这是新的共同基线，不能与上轮8条任务直接拼分母。
