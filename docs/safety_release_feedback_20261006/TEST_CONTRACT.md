# 测试范围

风险是：暂停相位仍重复产生差分指令；缓存或补偿绕开暂停；开手目标不等于真实脱离；碰后中止被计作成功；渲染改变物理；失败案例被丢弃。

软件检查覆盖真实 SkillReplayDelta 的重复采样反例、所有分量清零、环境槽位独立、连续六状态准入、任一条件失败超时中止、非有限输入中止和准入后再接触停止。首个测试失败是 tilt=10°恰在允许边界，测试修为20°而保留10°门槛，旧日志保留。

物理登记固定24任务、两组种子与槽位交叉。数值评分器在执行前冻结，完全独立于门控代码，保留旧任务门槛；中止与完整执行额外分别报告。每个原始数据块、所有原图校验SHA，渲染前后重新从PhysX读取位姿/速度和全关节位置/速度。原生命令清零不等于物理停止，因此记录实际速度积分和关节路径。

页面检查遍历24案例×2物体×4指标，120个三视角组，三段连续录像播放/seek、JSON下载、主板卡片、桌面与手机布局。独立数据分支所有原始文件在公开固定提交ZIP中逐文件核对SHA；网页文件回读校验与Pages工作流归属同提交。

通过这些检查不意味着全场景安全、完全接触校准、广域随机覆盖或硬件验收。
