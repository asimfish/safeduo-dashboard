实验范围

每条轨迹：60步零指令 + 450步持续随机动作 + 450步 IID 指令。四臂分别采样 0.005 / 0.015 / 0.025 / 0.05 弧度幅度，26个关节的方向分量独立采样；持续动作保持 1 / 4 / 15 / 30 / 90 / 180 步。两种随机阶段的顺序在每组内均衡。它们共享连续状态，不能当作两批独立样本。

执行的是原有全量准入和关节参考包络控制器；预测器只记录结果。保留原始六步执行器 FIFO、演员32条观测和几何豁免规则。违规指仿真球体安全裕度为负，并不等同于网格接触、真实损伤或硬件安全。
