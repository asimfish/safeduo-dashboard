# 队列延迟与固定目标制动：判别实验预登记

本轮冻结critical-only评测规则（原32行并入距当前锁线10mm以内的行，容量128、溢出中止），固定a31b actor、pending_guard配置、backlog_aware=false、物理参数。生产控制源码不改。

已知失效：seed12、32环境、±0.3rad初态、held_random保持90步、幅度0.015rad/步、10秒、6步严格目标FIFO，7/32违规。临近失败抽查42个完整线性约束集均可行，不等于动力学安全。

## 可区分的假设

1. FIFO本身扩大失效：同初态、同纯随机命令tape的0/3/6步延迟对照。若零延迟仍失败，不能把全部风险归因于FIFO。6步为重复控制，不增加独立证据。
2. 零增量仍留下危险持久目标：在冻结失败时刻之前12步，把受影响环境四臂的后续目标固定为触发前持久目标。该探针禁止新增目标，却不清掉已有目标偏差。
3. 当前姿态固定目标可制动，但必须等FIFO：同一触发表、同一输入，固定为触发前实测q，一次取样后保持，所有新目标仍走6步FIFO。记录首个固定目标实际到达、到达前/后违规、到达后继续运动。

两种制动探针只作用于冻结参考7个失败环境，其余环境保持原策略。触发时刻由既有失败轨迹离线确定，为诊断用事后时刻，不是可部署的检测器，不记入新安全成功率。不能称“提前知道失败即可安全”。固定实测q只取一次，区别于每步随惯性重新基准。手部关节保持原系统行为，不能假称全机器人停机。

先运行0/3/6步对照，使用其中新的6步重播生成停止时刻（首个非豁免违规step减12）。随后运行两种探针。验证初态和完整命令逐位一致；每个环境干预前物理q前缀逐位核对，若不一致降级为同输入诊断，不能用差值作精确因果结论。全程断言FIFO输出等于6步前的实际发送目标，禁止抢占、清队列或移到执行器侧。

除标准球距外记录实际发送/延迟送达目标、触发标志、固定目标。源文件、actor和配方SHA随协议保存。无新实机接口、无接触力、无连续碰撞证明；随机分布和局部初态未覆盖全部四臂工作空间。任何新失败、前缀不一致和观测器影响均如实报告；不根据结果调触发时刻或参数，不推广默认策略。

## 首轮后的顺序检查登记

正向0/3/6步得到0/32、1/32、6/32；6步旧重播为7/32，物理轨迹不逐位相同。停止探针均与第三cell控制的干预前q有差异，必须降级为同输入重播。但stored/measured两探针相互比较，六个受影响环境中五个q前缀逐位一致；env15旧目标持续重叠而实测q固定目标未重叠。该证据可判别停止目标方式，但事后时刻仍不构成可部署预防策略。

为区分延迟与连续cell的重置/运行顺序影响，固定所有已有参数，新增反向6/3/0步三cell对照。顺序检查的计数单列，不调目标保留规则，不改变停止探针的冻结触发表，不合并重复控制给独立安全率。补核两停止方式之间的q/qd/球心/命令/目标前缀和未改变的FIFO；若这些观测前缀不一致，保留范围限制。

## 反序后的独立进程条件登记

反序首cell100ms与上一轮critical-only的q、pre_qd、exec、controller_target和官方球距逐位一致，仍7/32；多cell第三窗口100ms为6/32。因此不是可直接归因于随机性的计数波动，存在运行顺序/重置历史影响，具体隐藏状态原因尚未证明。反序50ms第二cell为0/32，正序同样第二cell为1/32；不能用这种有运行历史差异的序列给延迟改善作精确因果结论。

固定全部参数，新增只含50ms的独立新进程首cell。0ms已存在正向新进程首cell；100ms有反向首cell与旧首cell逐位一致控制。三种冷启动条件单列为可复核主比较，全部顺序对照继续保留。新增步骤不改变任何停止时刻；停止探针同时保留对原第三cell控制的差异，并补列对冷启动100ms控制的观测前缀检查。stored六条、measured五条与冷启动控制的q/qd/球心/目标前缀一致，measured env30差0.110mrad，限制必须保留。
