# 严格目标FIFO与固定目标制动

冻结临界行方案，独立进程首窗口：0ms 0/32；50ms 1/32；100ms 7/32。连续窗口正向：0ms 0/32；50ms 1/32；100ms 6/32；反向：100ms 7/32；50ms 0/32；0ms 0/32。初态与完整随机命令逐位一致，运行历史影响已单列。

100ms首窗口与上一轮q/qd/exec/球距/目标/球心逐位一致=True，仍7/32。同参数第三cell为6/32，q与旧首窗口最大差0.989384rad。存在运行顺序/重置历史影响，隐藏状态原因尚未定位；不记作策略改进。固定目标诊断中，停止消息到达后仍有重叠的轨迹：旧目标2/6，实测q目标0/6；对原第三cell的12条q前缀不同，对冷启动控制有11/12条观测前缀一致。两种停止方式相互比较有5/6条观测前缀一致，可在该范围判别停止目标方式；env15旧目标仍重叠约62mm，实测q固定目标未重叠，但触发时刻是事后选定。实测q目标到达后仍有0.0029–0.0401rad可观测逆目标超调。全批次固定旧目标仍3/32违规，固定实测q仍1/32（未干预env31）；任何一组都不能报告全环境安全。实测q探针一次目标跳变超出普通增量约束，只能判别原因，不能直接推广。即使固定目标到达，也必须核验后续运动，不能用零输出宣称已停。本轮未修改或推广生产策略；现有100ms延迟候选仍不安全。

## 停止响应诊断

在本次100ms控制的首次失败之前12步，分别固定触发前旧持久目标、或一次采样的实测q。只作用于该控制的失败环境，停止消息仍等待6步FIFO，手部关节行为不变。这是利用事后失败时刻的诊断；下表观察不计入预防成功率。对原第三cell控制的q前缀均不同，仅作同输入重播；对冷启动100ms控制的观测前缀见表。 两停止方式相互比较，env[12, 13, 15, 22, 28]的q、qd、球心、命令、目标与待执行输入观测前缀逐位一致；隐藏物理求解器状态未记录。逆目标超调指新固定目标在运动反方向时，关节仍沿原速度方向额外移动。 全32环境也保留：固定旧目标仍有3/32违规，未干预失败env[31]；固定实测q仍有1/32违规，未干预失败env[31]。未因触发表未包含env31而隐藏该失败。 实测q固定目标探针一次跳变0.186–0.588rad，超过普通输出0.025rad/步的箱约束；这是显式绕过普通增量约束的机制诊断，不是兼容现有输出约束的修复。

## 证据边界

seed12；32环境×10秒；±0.3rad初态；纯随机保持1.5秒、幅度0.015rad/步。critical-only固定10mm/128行，actor32行/权重不变，backlog_aware=false；全部目标FIFO精确核对。主比较各用新进程首窗口；连续cell顺序组单列。冷启动0/100ms复用已完成首cell、只补一个50ms首cell。停止探针不增加独立安全窗口。既有连续cell结果保留为当时顺序协议下的实测值，不自动等价于独立冷启动条件；后续需按新条件复核。控制周期末球距测量不证明连续碰撞、物体任务、接触力或实机安全。

- 13项停止探针/FIFO工具契约CPU检查通过，不是安全策略验证。上一轮98项记录仍保留，不以本轮重复计数扩充。
- actor及全部生产源码/解析配置/协调器配置与上一轮逐项相同，四个关键核心源码SHA附于结果。全部仿真协议complete，初态无违规，命令/初态逐位匹配，延迟送达目标逐位符合FIFO。
- 正反序6个对照192窗口加一个50ms冷启动cell32窗口，共224个相关对照窗口。主比较96窗口复用其中首cell，不能重复计数。两个停止探针64个诊断窗口，不计为新增独立安全证据。保留旧候选7/192原计数，不加总为独立安全置信界。
- 未假设抢占队列、执行器侧运行或实机支持；无新视频、物体任务、接触力或连续碰撞证据。
- 实测q探针一次目标跳变0.185667–0.588272rad，普通输出增量上限0.024999rad/步；全部六条均超过普通箱约束。该探针是机制干预，不是经过原解析投影的可部署动作，尚未验证接触力/物体安全。
- 多cell的factor_manifest只保存最后一个cell的延迟；每cell真实延迟见cell_00x.json.window、协议design及本轮FIFO逐位审计，不能把最后cell的值套到整个矩阵。
- 尚待解决：当前线性历史目标预测与实际延迟动力学的偏差，前缀可重复性，以及在可部署检测器触发时的安全停机可行性。
