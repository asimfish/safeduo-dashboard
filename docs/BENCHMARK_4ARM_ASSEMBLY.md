# 四臂协作装配 benchmark（小红书视频）——逐帧学习笔记与对 R34 的修正（2026-09-07 晚）

来源：小红书 6a9c82f1…（"四臂协作装配 benchmark 搭建中"，MuJoCo，4×Franka，铝型材结构搭建 + 精细分拣 + 协作包装）。
我下载了 88 s 的演示视频、每 6 s 取一帧并读了左上角的分步字幕（参考帧存于面板 `gallery/refs/`，仅作内部对照）。

## 1. 他们的场景与任务（视频里能确认的事实）

| 要素 | 观察 |
|---|---|
| 布局 | 方桌，四台 Franka 分别立在四角（不是我们的两排面对面），全部朝向桌心；桌心是装配夹具 |
| 夹具 | 桌心一个已装好的**矩形铝型材外框**架在支撑块上；外框是任务的"工位"，不是被搬运的对象 |
| 被操作件 | 一根**横梁（cross member）**——与外框同截面的型材；一枚**紧固件（fastener）**；四角小料箱里立着若干螺栓/销（"精细分拣"的素材）；一块布上放着工具（锤/扳手类） |
| 分步字幕 | ① Positioning all four arms ② Establishing physical grasps ③ Transporting and installing the cross member ④ Installing and striking the fastener ⑤ Run stopped |
| 协作形态 | 横梁由**两臂同时握住**运送并放进外框（长件双手共持）；第三臂在横梁到位后**装紧固件并敲击**——装配时多臂在同一小区域内近距离作业 |
| 抓取 | 字幕强调 physical grasps（真夹持，非吸附），与我们 R27 的路线一致 |
| 机位 | 3/4 俯视全景，四臂 + 整张桌子入画（与 owner 对 camW 的要求一致）；UI 上有分步字幕 |

## 2. 对 SafeDuo R34-A 的修正（把"像他们"落到具体设计）

1. **旗舰任务改为"装横梁"（cross-member install）**，而不是抽象的"型材递送"：
   - 夹具 = 外框：两根固定的 4040 长边（或完整矩形框）架在立柱上，长边上留两个**搁座/角码位**；
   - 被操作件 = 一根 4080 横梁（0.78 kg 实心，正好需要两臂共持——探针 5 已证明单手抓不住，这不再是缺陷而是任务设计）；
   - 流程 = ① 四臂就位 → ② F_L、F_R 两端物理夹持 → ③ 共持运送、对位、落入搁座 → ④ U 臂取紧固件（角件/螺栓）装入并**下压/敲击**（接触密集、近距离）→ ⑤ 松手撤离。
   - 这是 R32 的天然解：横梁 300–450 mm，两手相距 ≥20 cm，直接双手共持不触跨机安全线；而 U 臂在两只 F 手旁边装紧固件，正是离合器要守的"多臂在同一小区域内作业"。
2. **料箱与紧固件**：四角放 KLT 小料箱，里面立放紧固件/角件（可捏 ≥3.5 cm 的放大版），构成"精细分拣"子任务：U 臂从料箱取件 → 递到装配位。
3. **工具敲击**：Isaac 里用一个 T 形/圆柱工具（已有 obj_tool）由 U_R 持握，对紧固件做下压或敲击；对离合器是"高速接近 + 接触"的定向场景，比现有 head-on 更贴近真实工序。
4. **分步字幕**：录制器的 phase 名改为人能读的工序名（Positioning / Grasping / Transporting / Installing / Fastening），进视频叠层。
5. **不照搬的部分**：他们四臂围一圈、全部同款 Franka；我们是两排面对面、异构（FR3 + UR5e，五指手）。这正是差异化：跨机型、跨操作员的共享工作区安全。

## 3. 落地清单（设计线）

- [ ] `frame_base_fixture` v2：从"两搁座 + 套管"改为"矩形外框 + 两搁座"，长边 4040×600，短边 4040×300，立柱高 100 mm（v8 布局，U 桌 x≈−0.40）。
- [ ] 横梁 = `profile_4080_L300`（0.78 kg，双臂共持）；备选 `profile_4040_L300`（0.39 kg，单臂）。
- [ ] 紧固件 = `conn_cube_4040`（40 mm）放入 KLT 料箱；工具 = 现有 `obj_tool`。
- [ ] 任务判据：横梁两端落座偏差 <5 mm、yaw <5°、settled；紧固件与角码位对中 <10 mm；全程零 VIOLATION；两只 F 手最近距离 ≥30 mm。
- [ ] 探针顺序：双臂共持搬运（复用 box_colift 的 PalmFrame/两端夹持）→ 落座 → U 臂取件装入 → 敲击。
