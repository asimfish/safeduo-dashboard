## 0. 这组工作的整体图景（Zihao Li / Weiming Zhi，ZENO AI × 悉尼大学 PAIR Lab）

作者主页的研究纲领是"**交互即智能的单位**"（Zeno-1 协作物理智能架构）：每台机器人跑同一个 3B 模型、30 Hz、无中央调度、无特权伙伴状态——运动、物体响应、接触本身就是接口；一段紧凑的交互记忆让一个策略跨 8 个子任务、10 分钟不重置；"接触前先想象"（predictive introspection：选择让伙伴后续行为更好的动作，87% vs 61%）。三条已发表的支线：
- **SAI**（CoRL 2026）：协作策略如何从单遥操作员课程里学出来；
- **TRACE**（CoRL 2026）：跨时间的因果记忆；
- **TriPilot-FF**（RSS 2026，arXiv 2602.09888）：力反馈全身遥操——用激光雷达的接近信号在**脚踏板上渲染阻力**，"在没有显式避碰控制器的情况下把操作员的指令塑形为避碰行为"，并把遥操反馈信号喂进 ACT 提升策略。
另有 "Robot-Friendly Scaffolding with Passive Error Correction"（锥形连接件把不完美对位变成可靠装配）、TAPOM（细长物体在狭窄通道的拓扑引导规划）。

**对 SafeDuo 最重要的一句话**：TriPilot-FF 与 SafeDuo 解决同一个问题（遥操时不撞）走了两条路——他们**在操作员这一端做触觉塑形**（人感受到阻力而改指令），我们**在机器人这一端做指令门控**（离合器 α+p 与解析兜底）。论文里应把这对关系写清楚：触觉塑形不保证零碰撞（"shaping toward collision-averse behaviour"），门控给出可证的硬兜底；两者可叠加——我们的离合器 α 完全可以回传成踏板/手柄阻力。

## 1. SAI：精确内容

| 项 | 他们 |
|---|---|
| 平台 | 两台**双臂移动机械臂**（3 维底盘 + 14 维臂手 = 17 维状态/动作），TriPilot 全身遥操，单操作员 |
| 任务 | Bed-throw / Tablecloth（可变形物共展开）、Laundry（共享工作区分拣）、Painting Transport（刚体共搬） |
| 三阶段数据 | ① A 对柔顺人类伙伴的单侧示范；② 冻结 π_A 部署，遥操 B 对着它学——同时给 A **加有界部署扰动：速度缩放、动作噪声、时序偏移、初始物体扰动**；③ 双机闭环，只在协作失败边界对 A 做 DAgger 式稀疏干预，干预样本上采样、**动作维度掩码**（只监督被纠正的维度），干预集约为基线数据量的 30% |
| 策略 | ACT + 历史 token（30 步窗口对数采样 12 帧，单层 GRU 512）+ 级联动作头（先底盘 3 维再臂手 14 维）；冻结 DINOv3；观测含**臂端力矩反馈**；chunk 100、时序集成 0.01 |
| 伙伴视觉 | 对人类伙伴区域做实例分割 + 膨胀 + 随机化（RGB 噪声 / 模糊 / SD 修补），防策略学到"人形"捷径 |
| 指标 | Success（局级，30 局/条件）；**Phase Sync**：每任务预定义 2–5 个检查点，双机在**预定时序容差内**完成且无破坏性交互才算同步，分母 N×K，失败局未达到的检查点全计失败；**Yield/Wait**：在预定义的"伙伴延迟机会"上，慢下/等待/让步/调姿/等伙伴就绪再继续算正确 |
| 结果 | 四任务 Success 从独立模仿的 23–50% 提到 53–70%，Yield/Wait 27–47% → 68–72%；ACT 与 Diffusion 都有效 |

### 我们采用（带验收）
1. **相位同步率进四门**（R35-③）：为每个协作任务族写 2–5 个检查点与时序容差（例如 cross_member_install：两端同时夹持 / 同时抬起 / 到位落座 / 紧固件到位），门控下的同步率 ≥ raw 的 90% 作为"离合器不破坏协作结构"的验收；未达到的检查点计失败，与他们同口径可比。
2. **伙伴延迟探针进 L2 场景库**：在交接/共搬相位随机让一方操作员停 0.5–2 s，度量另一臂不过度刹停（误刹口径）与恢复后不死锁；对应他们的 Q2 实验。
3. **分臂顺序微调**（R35-①）作为 R33 死腕→活腕迁移的低成本路线：冻结 F 侧门控头微调 U 侧（对应 Stage 2），交换（Stage 1 补），最后只在迎头窗口做稀疏干预式微调、**只监督出问题的臂的 α/p 维度**（对应 Stage 3 的动作掩码）。验收：stack_fix 四门硬门全回且误刹(arm) ≤ 0.143×1.5。
4. **Stage-2 式伙伴扰动**直接可搬进我们的随机操作员流：在 L1/L2 流里给一方指令加速度缩放、动作噪声、时序偏移——这正是 R31 结论里缺的"伙伴分布"变量。
5. **写作**：动机段用他们四类失败（不等待、不让步、拉放不同步、共享物失控）；相关工作里把 SAI（数据课程）、TriPilot-FF（触觉塑形）与 SafeDuo（指令门控 + 硬兜底）放在同一张表里。
