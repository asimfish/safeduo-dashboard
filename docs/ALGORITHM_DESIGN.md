# SafeDuo 算法设计（v1，2026-09-08）

面板"算法"页的正文版。框图：`diagrams/algorithm_v1.svg`（`build_algorithm_svg.py` 生成）；结构化内容：data 分支 `algorithm.json`。**任何训练配方 / 网络 / 执行语义 / 代价与乘子的改动都要同步这三处并记变更日志、版本号 +1。**

## 1. 一句话

把"遥操安全"建模为**约束强化学习**：策略只学一个逐臂离合器——危险概率 α（×4）和刹停量 p；安全时遥操指令逐位直通零衰减，涉险时只冻结涉险臂；三条碰撞代价通道（跨机 / 自碰 / 桌面）用 **PID 拉格朗日乘子**自动满足上限；解析 backstop 是可证的最后一道。训练与真机执行同一套语义（R17 产品语义：模型 = 遥操数据采集的安全滤波器）。

## 2. 问题建模

| 项 | 内容 |
|---|---|
| 状态 / 观测 | 四臂 q, q̇ + 当前指令 Δq_cmd（28 维）+ 成对特征 [距离, 接近速度, 类别 onehot]（跨机 / 自碰 / 桌面最差对）+ arm-aware 配对观测（R15）+ 上一步 α/p（p2-obs，R18）；共 275 维，状态式无视觉 |
| 动作 | α₁..α₄ ∈ (0,1) 逐臂危险概率（执行时 0.5 二值化 = 离合器）+ p；联合 Beta 分布头（有界支撑，避免高斯策略卡边界） |
| 奖励 | 指令保真（执行 = 遥操输入的程度）− 不必要干预；逐臂 α 均衡正则 w 0.01（防 F_L 成"约束汇"）；PBRS 余量项 |
| 约束 | cross：scale 4，limit 0.04，λ_max 0.35；self：17，0.05，0；table：19，0.05，0.05 |

为什么是约束 RL 而不是奖励加权：v3 把安全项放进奖励，出现"冻结比活动更划算"的地形病（两个 seed 在 277–450 迭代塌缩）。v4 起 margin/tube 代价移出奖励进约束通道，乘子自适应——安全成为被满足的约束而非手调系数。

## 3. 运行时回路（每控制步）

1. **操作员**：真机 = 两位操作员各控一排；训练期 = 技能库回放（13 族 + R24 四臂/共持族）+ 全域随机漫游流（R25），幅度课程 0.03→0.10 rad、混流 0.2，受控会合豁免 v_rel ≤ 0.15 m/s（R28）。
2. **观测构造** → 3. **策略**输出 α, p → 4. **离合器**：α<0.5 直通；α≥0.5 仅冻结该臂；后撤方向直通（R30）；恢复 = 操作员逐臂解锁（R17）；R19 执行层旁通保证 safe 区解析栈不碰指令 → 5. **backstop**：几何距离 + 前瞻 0.06 s 速度感知阻尼带；结构行豁免（R29）；活腕 armature + 重力补偿（R33）= 栈 `fix2_la06` → 6. **机器人 / 仿真**：Isaac Lab 4096 环境，v8 布局，R34 工业装配物体。

## 4. 训练信号（PPO-Lagrangian，自建循环 `safeduo/algo/lagrangian_ppo.py`）

- **代价通道**由标准观测重建（无 env 钩子），有效性感知 GAE（真终止不自举、超时自举）。
- **PID-Lagrangian**：每迭代按 rollout 均值更新；kp 0.5 / ki 0.05 / kd 0.1，积分限幅；λ_max 防绕组；变化率 ≤ 0.01/更新防震荡。
- **PPO**：裁剪 0.2、GAE 0.95、四价值头（reward + 3 代价）；熵系数 0.006↔0.012 由熵 EMA 触发（−3.5 / 释放 −3.2 / 代价门 0.9）；48 步/环境/迭代 × 3600 迭代 ≈ 7×10⁸ 步。
- **危险 BCE 辅助监督**（R18/R28）：事后标签 = 未来 30 步内该臂真越线；尾部掩码、正负平衡，w 0.5；α 死区惩罚 w 2.0；会合豁免不计危险 → α 成为校准过的危险分类器。
- **训练期 α 二值化**：0.5 处直通估计器，消除训练-执行失配。

当前配方 aF = a27 命令行去掉 `--resume`（`scripts/forensics/a100_train_aF.sh`），env `duo_env_v7_r18_fix2_v8_la06.yaml`，课程 `delta_curriculum_v7.yaml`，seed 46，30109 GPU2。

## 5. 谱系

v3（安全进奖励，塌缩）→ v4（PID-Lagrangian + Beta actor）→ v6.x（课程 / λ 重定标 / 抗塌缩）→ v7（真机资产 + arm-aware + 几何壳）→ S8/R18（离合器语义 + 危险 BCE）→ R19/R28（旁通 + 会合豁免 → a27 过硬门）→ R29/R30/R33（最终执行栈）→ R31 负结果（warm-start 不闭合）→ **aF**（v8 + 最终栈从头重训）。
