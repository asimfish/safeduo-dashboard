# SAI 与 TRACE 对 SafeDuo 的启发（2026-09-06）

两篇均为 Weiming Zhi 组（浙大 / 悉尼大学）CoRL 2026 论文，小红书帖「CoRL + 2」介绍。

## 1. SAI — Robots that Collaborate: Sequential Asymmetric Imitation（arXiv 2606.16490）

**内容**：双机器人物理耦合操作（铺床单、桌布、收衣、共搬画作）。失败多源于时序失配（不会等、不会让、拉/放不同步）。
提出单遥操作员三阶段课程：① A 对柔顺人类伙伴学单侧示范；② 冻结 A 部署，遥操 B 对着 A 学（B 见到未来伙伴的真实时序与误差）；
③ 双机闭环，只在协作失败边界对 A 做 DAgger 式稀疏干预并加权回放。去中心化、无通信。指标：Success / Phase Sync / Yield-Wait。
对 ACT 与 Diffusion 两种 backbone 都有效；伙伴延迟实验中 SAI 会减速等待再恢复。

**对 SafeDuo**

1. **动机对位（论文必须回应）**：SAI 声称不需要同步双操作员示范，看似削弱「安全采同步协作数据」的动机。但 SAI 的第二、三阶段都是
   人遥操一台机器人与另一台自主机器人共享工作区——恰是最需要离合器的场合。结论：SafeDuo 是 SAI 式与同步式采数的**共同安全前提**；
   相关工作里这样写，动机段可用 SAI 的失败模式（不让步、不等待）说明为什么保真与死锁指标重要。
2. **R31/R33 对症**：a28/a29/a30 三次 warm-start 都以「U 臂误刹翻倍」失败，本质是伙伴分布漂移（死腕→活腕）下的联合适应失败。
   SAI 的处方是**非对称分阶段**：冻结一侧、只让另一侧适应。迁移到离合器（集中式 α/p 头但逐臂输出）：
   - 阶段 1：冻结 F 侧门控头，只微调 U 侧头（stack_fix 环境）；
   - 阶段 2：交换；
   - 阶段 3：只在失败态（`headon_violation_trace.py` 可复现的迎头窗口）做稀疏「干预」微调，样本加权、动作维度掩码只监督出问题的臂。
   成本约为完整课程重训的 1/4，作为 D2 之前的候选（R35-①）。
3. **过程指标**：四门只有 done / no-deadlock，没有「离合器是否保住了两位操作员示范的协作结构」。借 Phase Sync 定义
   **相位保持率**（门控下双臂检查点时序偏差 ≤ raw 的容差）作为 G4 数据质量指标；借伙伴延迟实验做 **暂停一方操作员** 的 L2 定向探针，
   检验另一臂不被过度刹停、恢复后不死锁（R35-③）。
4. **框架对照**：SAI 的动作维度掩码干预 ≈ 我们的逐臂 α 进展预算；SAI 的柔顺伙伴 ≈ 我们的随机操作员流（L1）；可在讨论段一笔带过。

## 2. TRACE — Trajectory-Routed Causal Evidence / Memory（arXiv 2606.14551）

**内容**：延迟证据任务——早期线索（物体身份、目标选择）在决策点前已离开视野，当前观测不是充分状态。TRACE 用机器人状态轨迹的
**路径签名**（有序、定长、对时间重参数化不敏感）作为键，把线索可见时的视觉/状态证据写入固定预算的潜在记忆，到歧义点按轨迹键读出；
以轻量适配器接入任意 visuomotor policy，不改 backbone / 动作头 / 目标。

**对 SafeDuo**

1. **误刹-安全张力里的记忆成分**：一次接近是受控交接还是迎头冲撞，由最近几十步的轨迹形状决定，而不是瞬时状态。R28 的 coop 豁免只看瞬时
   闭合速度，R33④ 又暴露了动量。给每臂最近 H 步（如 30 步）关节速度序列取 2–3 阶截断路径签名，作为 α/p 头的额外「意图特征」；
   纯 torch 几十行，可在 4096 env 流水线里做消融（R35-②）。预期：同硬门下误刹或保真改善；若无改善也是干净的负结果。
2. **滞回死锁是记忆丢失**：锁上后离合器不记得为何锁，R30 的 retreat_release 是手工写的记忆。用「介入时刻的轨迹键」决定释放条件，
   比手工规则更有原则，可作为 R30 的后继。
3. **写作**：两篇同组工作一并引用；TRACE 放在协调器观测/历史设计的讨论中。
