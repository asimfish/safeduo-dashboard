# 第二轮安全完善：速度一致性与随机覆盖

继承候选 `duo_env_a31_lag_guard.yaml`，固定 a31b checkpoint、原始几何、dt 和速度上限。上轮 416 个匹配窗口均未违规，但 l1_full/seed8/env2 的 self_U 最小余量仅 0.7808 mm；不能因此声称全面安全。

## 先诊断，再改策略

观测：row7276 在 t138--152 的距离下降，而 arm-only `J qd` 为正。三个可区分假设：

1. 未控制的手部关节造成额外闭合运动：all-joint Jacobian rate 应与 body-derived rate 一致，而 arm-only rate 不一致。
2. Jacobian 与球心的参考点/坐标系不同：all-joint rate 也与 body rate 不一致；需比较 COM 与 link offset，有限差分验证。
3. 瞬时速度和跨步积分存在变化：两种 rate 在同一时刻一致，但下一步距离有限差分不同；需比较前后速度及加速度。

运行 `kinematic_diagnostic`：同一配置、seed8、amp0.015、32 环境、l1_full、5秒；记录完整关节速度、活跃 pair ID、body rate、arm-only/all-joint rate。诊断窗口是重复观测，不增加独立样本数。

## 随机覆盖

旧 IID 增量会在 home 附近相互抵消。增加 sample-and-hold 的纯随机关节增量，每个随机向量保持固定控制步数；仍不引入目标点或状态引导。比较相同幅度、种子、时长下实际关节范围与六臂对接近暴露，同时保留逐步 IID 对照。命令 tape 及初态必须跨方法完全相同。统计按 seed/分布分组，不使用相关窗口宣称 IID 安全置信界。

## 交付准则

- 原因证据需能区分上述假设；改动有可失败的行为回归测试。
- 修正须完成原触发条件前后对照和冻结的新增随机压力组，报告新增违规。
- 报告实测间距、运动量、执行/指令比例及覆盖，不能以停住或未接近代替安全效果。
- 只报告球层非豁免 margin < 0 的仿真结果；真实物体协作、接触/力和动力学扰动保留为未验证范围。
- 网页面板保留历史负结果，新增报告和可核对曲线。
