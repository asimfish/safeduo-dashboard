# 核验与候选状态

本轮新增两项实验因素：启用已存在的闭合扣减分支，以及在评测适配器中合并全部临界安全行。冻结控制核心、原配置与actor；新debit配置和critical适配器均未推广为默认策略。

临界行候选：原初态回归0/32，100ms/10秒重播7/32，seed14四组128窗口0违规。该候选仍有7/192窗口违规；不能宣称安全已完成。只启用debit与联合版本在原初态均为15/32，负结果保留。

98项相关CPU测试通过，旧配置/旧行选择反事实产生RED。原初态取证轨迹逐位一致；延迟取证只共享初态和命令，物理轨迹不同，明确降级。完整求解器约束独立LP重算：真实p、历史扣减、alpha、authority钳制与目标限位均纳入；抽查残差与记录差小于2µm。当前线性可行不等于PD动力学安全。

所有完成的协议、core源码与actor身份、FIFO时序、纯随机tape及初态逐项核验。漫游采用状态反馈，只匹配种子和源算法。保护仍等待相同FIFO，未假设抢占接口。本地浏览器实际显示4组因素、4个新种子条件、历史30组与冻结参考8组；所有曲线切换、有限SVG、390px布局检查通过，无页面异常。
