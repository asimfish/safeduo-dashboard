# 候选冻结：有速率约束的目标积压限制

依据旧60317411重播：全部q、输入、执行、裕量、控制与设备目标逐帧相同；历史目标与实际FIFO完全一致；39/64违规。所有首次违规行在碰撞时已进入约束，32个首次桌面事件没有positive-cap结构行跳过；234个精确线性可行性快照9个不可行。多条首次失效在当前目标开始退让时，待执行旧目标及惯性仍明显闭合。本候选是对目标积累的缓解实验，不声称证明唯一根因或闭环安全。

固定三个System0条件：原dynamic512；box_only（将传入原投影的cmd限至同一速率/软限位区间，包括R19直通）；envelope_050（在box_only基础上增加目标相对实测q的±0.050rad区间）。0.050选择为原每步0.025速率预算的两步目标余量，未进行仿真结果调参。保留原alpha/p、全类lookahead、条件桌面豁免、actor32、6步严格FIFO。包络与本步速率/软限位无交集时只向最近可达端点移动；无队列清空、目标重置、越速率跳变或隐藏物理保护。

算法改变了alpha作用的输入，固定在机制说明中；限制积压不等于保证物理接触安全。solver残差、不可达包络、静止输入主动退让都保留。禁止调整速度、行容量、随机幅度、失败终点或初态筛选以使候选看起来更好。

开发回归：旧60317411分别box_only与envelope_050，两新进程×64×完整16秒，baseline已有逐帧等价重播。不重新计入新外部随机轨迹。冻结后无论开发结果优劣，都不再调参。

独立留出：三个已先登记的新种子152684921/198470327/237901613，每种子64初态（6风险配额各8+general16），同tape、q0、设备cuda:0，fresh process分别raw、baseline、box_only、envelope_050。12条件共768窗口，192新外部随机轨迹；full16s包括零输入60步+原900步强随机，所有失败/无效/未完成列入。原全源码及actor、bank、参数与helper哈希在任何留出压力结果前冻结。

主要指标：全窗口任何官方非豁免负球面距离；补充深度<-5mm、cross/self_F/self_U/table、首次随机到达前事件、实际FIFO逐帧匹配、软限位、实际目标增量上限。配对比较baseline与两因子candidate及raw；不宣称IID置信。记录26关节覆盖、6臂对压力到达、4臂真实活动量、外部/执行L2、路径、目标积压和不可达比例。安全与操作能力并列，不以更少运动作为充分安全证据。

预设准入：独立留出零违规、零无效、全部FIFO/速率/软限位契约通过只是本压力批次的必要证据；实际物体任务、握持、连续接触/硬件迁移仍需独立验证。本候选默认不进入生产。
