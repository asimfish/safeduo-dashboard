# SafeDuo 科研实验协议 v1

状态：规范与审计工具冻结；最终留出输入尚未注册。已有运行保持原协议，
不能追认成本协议的独立最终测试。目标是可复核地评价 System 0 在四臂协作
中的安全效果、任务能力和局限。软件测试通过不等于物理实验充分。

## 结论与测量对象

分开报告四种证据：原有球体几何距离的非豁免负值、独立碰撞/接触测量、
任务执行是否成功、预测/投影是否符合自己的数学约束。原始 d 是球面间隙
或球体到桌面的有符号距离；d_min 是另一个制动/准入阈值。d<0 的球层
事件不能自动解释成真实网格接触，也不能用提高容差或扩大豁免消除。

主科研结论需要同时满足：候选减少预注册的安全事件，任务成功率和进度
没有通过停滞而明显下降；危险类型、失败反例、置信区间和暴露不足均可查。
仅平均预测误差降低、投影残差为零、初始状态无碰撞、视频看起来顺利，
都不足以通过该门槛。

本协议参考 NIST 的任务驱动性能测量框架，将感知、运动、操作和安全联合
评测。这是仿真科研协议；ISO 10218-1/2:2025 的公开范围分别涉及工业机器人
及应用/工作单元。没有读取标准全文、逐条评审或硬件验证，不能作符合性声明。

## G0：测量系统与任务有效性，先于大规模新任务实验

1. 输入包含物体原生位姿、线/角速度、尺寸、目标、时间戳以及有效/缺失标志；
   记录实际送入策略/规划器的张量，不只记录环境真值。物体感知误差独立计量。
2. 物体静态布置通过到达与操作净空检查；记录无法抓取/过密/初始违规的布局，
   不把它们暗中剔除后声明全面。正常可操作布局和恢复挑战是两个分母。
3. 独立原生 PhysX 接触或已验证的网格距离测量；明确允许的手指—物体接触，
   同时检查臂—臂、臂—桌、臂—障碍、携带物—机器人/环境、意外物—物接触。
   与球层距离做受控分离/接近/接触扫掠对照，查漏报和误报。网格 oracle
   自身也须有解析几何、原生状态和坐标校验，不能只换另一个未验证代理。
4. 真实夹持小样本：物体被抬升>=100mm、保持>=2s、释放后按动力学下落；
   同时保存手指关节、接触、物体相对姿态和约束清单。以上是本研究选择的
   工程验收阈值，不是工业标准阈值。传送位姿、隐式绑定或粘连不算夹持。
5. 每个任务分别冻结成功目标、容差、时限、对象、有效初态及失败类型。
   用移走目标物/错位目标/取消夹持等负例证明成功判据确实会失败。
6. 俯视、正视、侧视及四臂局部视角记录内外参、原生状态和可见性/遮挡；
   在数值实验同一次执行中采集最小必要图像。独立重放只能支持自身状态，
   不替代未通过的跨运行一致性检验。多相机只提供观测，不认证毫米安全。

G0 任一必要项缺失：任务实验标记 blocked/invalid，不纳入完整任务安全成绩。
当前 q 随机实验可继续，但只支持该受限运动/几何层结论。

## G1：四臂操作空间与共同工作区

四臂分别测关节位置、速度、末端位置与方向、桌面高度带、近/中/远伸展、
奇异附近和关节边界。六种臂对全部纳入；另外必须测四臂同时活动、三臂
让行、共享物体和相交搬运。关节空间均匀不等于末端空间均匀。

建立独立、冻结的可达参考图：固定场景与关节限位下的 FK/IK、姿态、
障碍/自碰条件、可达证明或失败状态分别记录。先用实际原生末端状态验证
参考运动学，再定义可达体素分母。没有分母时只报告到访体素数。

覆盖度包括26个关节的一维格、全部325个关节对（72个臂内、253个跨臂）
二维格、六臂对相对末端位置/方向、风险距离/速度/高度带，以及四臂共同
状态的覆盖增长曲线。低维覆盖不能当作完整26维体积覆盖。

空白格先区分不可达、已证明可达但未测、未知。不能用观察到的 min/max
缩小分母，也不能把所有未访限位矩形格都当作真实可达空间遗漏。
报告完整轨迹与第一次负球层距离前缀的覆盖，不能只展示违规后扩张的范围。

## G2：随机运动与针对性压力

六个分布族分别统计：每步独立的关节随机输入；多持续长度的随机输入；
低频平滑/相关输入；大范围分层初态加随机运动；四臂同步相向/交叉/让行；
冻结开发阶段设计的边界、突变及对抗流。纯 IID 必须保持状态无关，不能
把目标追踪、条件拒绝或对抗优化称为纯随机。

方向正负、四臂幅度、时间相关性、频谱、保持长度、零输入比例与作用范围
均验证；随机数流按初态/指令/扰动分离。初态的拒绝规则、候选总数、失败
原因及接受率公开。正常起点、初始违规恢复、零指令漂移独立统计。

分别记录原始意图、实际送入控制器的命令、发出目标、FIFO、实际送达目标、
实际 q/qd。同初态/同外部指令的配对要逐位检查；状态反馈任务允许命令不同，
但必须说明这是同高层目标/场景，而非同低层指令。

## G3：真实任务，覆盖单臂、双臂及四臂

任务族：单臂抓取放置（逐臂）；六臂对交接；六臂对共抬共搬；两对同时搬运；
四臂共享载荷；四臂相交搬运与让行；放置/插入/装配；突发障碍与中途扰动。
每个族包含容易、中等、困难布局，明确活跃/保持的臂以及真正的协作依赖。
四条随机命令同时执行不算完成了四臂共享任务。

共同报告：完成率、仅安全且成功的比例、进度、耗时、停滞/拒绝率、轨迹路径、
关节跨度、末端里程、携带物偏差、掉落、允许/禁止接触与安全事件。所有超时、
执行器饱和、无解、非有限值、初始化失败和软件中止保留；缺测不是通过。

## G4：公平对照、消融和稳健性

主对照冻结为：无保护/原任务策略、仅目标速度限制、原始 backstop、当前
System 0、预先选定候选。零指令/停止策略仅为诊断；消融依次关闭候选的
观测、队列预测、全量准入、关节参考包络，分清每个机制作用。不能只比较
动作更小的候选和动作更大的基线。

若声称动作强度匹配：在独立开发集校准缩放，冻结后检查实际路径和跨度
分别在预设±10%内；不通过就标记不匹配。实际任务还须报告进度/完成率。
禁止根据最终留出失败再调幅值、阈值或挑轨迹。

稳健性分块：延迟0/2/6/12步及抖动/丢帧；传感噪声/时间错位/遮挡；载荷、
摩擦、阻尼和执行器参数在设备/任务允许域内的固定扰动；未见物体/布局；
16/60/180s长度及长时间漂移。先测主效应，再冻结最危险且合理的交互组合，
不宣称跑过某几个主效应就覆盖了所有组合。物理参数只在 setup 时设置，
保留原始参数、版本和接触容量，避免不受控的运行中改材质。

## 数据划分、样本量和统计

开发/调参、机制验证、最终盲留出按初态、布局、指令种子和对象 ID 分组，
同轨迹不能以帧切开泄漏到两边。所有已知旧结果属于回顾/开发证据。
当前两个正在运行的注册批次保留各自定义，仅在相符范围提供机制验证；
不追认为新规范的完整最终留出。

最终每个主要随机分布族暂定至少20个独立种子块，每块64个案例。
这是运行重复与分层分析的设计下限，不是充分性的数学证明。最终数量须
在开发阶段按预先选定的最小效果、配对不一致率、块内相关性、置信水平
和功效计算，再于看最终结果前冻结；如功效不足，只能报告不确定。
真实任务和稳健性各关键层也按功效/精度单独确定样本，不借随机池凑数。

主终点是完整窗口/完整任务的事件率，不是把960帧或9021行当作独立样本。
同初态多方法是配对案例，重复运行是重复测量，跨种子块可能相关。
报告每种子、每风险、每任务的结果；对比较效应使用预先冻结的分层块
重采样/块级分析与敏感性分析。主比较一个，次要比较做 Holm 校正；最坏层
和新增失败单列。小样本 exact McNemar 也需要独立案例假设，不能绕开相关性。

零失败仍需上界。仅在独立、同一冻结分布的 Bernoulli 试验假设成立时，
单侧95%零失败上界是1-0.05^(1/n)。例如192个独立试验即使零失败，上界约
1.55%；目标上界0.1%至少需要2995个独立且零失败的试验。这是样本设计
示例，不是当前数据的可靠性结论，也不覆盖未测任务或工业硬件。

## 重复、证据与最终门槛

同 GPU/版本/并行度做重复运行；再做数值/渲染边界、GPU/批量变化敏感性。
逐位一致、容差一致和统计一致分别给出，不能把一种当成另一种。复跑同样
192个初态不增加初态覆盖。现有相机跨运行 exact FAIL 必须保留。

每个正式批次冻结：源/配置/模型/资产 SHA、输入生成器与所有随机种子、
环境版本、原始采样/拒绝、分母、终点、统计规则、接触/豁免语义、相机参数。
保存原生状态、输入输出、FIFO、全量几何/独立碰撞、物体状态和全部失败，
并提供公开的紧凑表、可下载统计、典型成功/失败视图及复算脚本。

最终状态只能是：范围内通过、未证明、失败或无效。充分性需同时有任务
有效性、覆盖分母/暴露、独立测量、配对对照、统计精度、重复性和失败闭环。
研究门槛通过也不自动批准真实硬件运行。

## 当前执行顺序

先复算已封存768窗口的全关节对覆盖、非负球层前缀覆盖、越界与真实运动；
此审计是回顾性新分析，不计新物理样本。等待已注册动态预测批次完成，
