机制改变与实际发现

旧机制的 15mm 名义预留要求超出目标修正盒可实现范围。新机制围绕实际 FIFO 队尾构造所有 9,021 个原始几何行与 74 个原生自由度的速度／力矩约束，再由独立 float64 准入器检查实际 float32 目标。无法求得合格动作时，明确记录 UNQUALIFIED；保留六个已排队目标。

独立审计确认模型和原生证据完整，但真实关节、速度、接触仍有失败。34/64 状态通过前六控制步的主判据，只代表短前缀。安全阈值保持原始距离 <0、伙伴逐点标量力 >0.1N；名义模型通过不构成 FIFO 未来安全证书。

初态手部覆盖为随机开手族；尚未覆盖完整 48 个手关节范围、带载夹持和真实硬件。
