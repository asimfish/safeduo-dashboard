# 独立进程与限幅停止诊断：预登记

冻结 actor、pending_guard、critical-only 10mm/128行评测包装，backlog_aware=false。不修改生产控制源码。对上轮源码的唯一差异为已记录的 replica_visuals.py，保留该变更；本轮另跑当前源码冷启动控制并比较旧轨迹，不假定可视化变更无物理影响。

四个条件各由单独的新 Python/Isaac进程运行且仅含一个cell：未干预控制、停止提前12/30/60步。每个条件 seed12、32环境、±0.3rad初态、held_random每90步换向、0.015rad/步、10秒、6步严格FIFO。独立启动驱动验证单cell完成、参数和进程ID，保留失败协议/日志，禁止重用或覆盖已有输出。

三种停止条件均从上轮冻结 stop_schedule.json 的同六个环境首次失败时刻减固定提前量生成；env31仍无触发，必须保留全32环境结果。参数在本轮任何仿真之前登记，不依据本轮结果改时刻。这是事后制动探针，不是可部署的前瞻检测器，不计为新增独立预防安全成功率。

目标只在首次触发采样一次实测q，并裁剪至现有软限位；随后每个控制周期从上一已发送目标向该固定点逐坐标移动，增量不超过运行时backstop的vmax*dt（约0.024999rad/步）。实际目标都进入现有FIFO，禁止清队列、抢占或改到执行器侧。手部非受控关节保持原行为。探针遵守增量箱和位置软限位，但停止目标不经过原距离行投影，不称完整兼容现有投影或可部署修复。

判别目标：原12步（约200ms）提前量加上限幅后是否仍足够？更早固定提前量是否改变停止响应？若仍失败，说明满足输出箱并不足以保证制动；若未重叠，也不证明存在能及时触发的检测器或全空间安全。

核验全部32环境初态、命令逐位匹配；FIFO逐位精确；所有实际已发送增量和软限位（浮点容差5e-7rad）；全环境非豁免球距与episode JSON一致；干预前观测q/qd/球心/目标/待送达输入是否逐位相同。记录触发、首消息到达、目标收敛步数、到达前后失败、失败环境、新增失败及最小球距。不排除未干预或失败样本，不把反复同输入探针合并成IID统计。

测试契约：纯函数固定采样/逐步接近/箱与软限位/无触发透传；真实TargetDelayQueue证明6步无抢占；真实子进程边界证明每条件独立启动，拒绝多cell/失败/旧输出。首先保留缺失新功能的RED，再最小实现。CPU契约通过不代表仿真安全。

当前边界：仅控制周期末球层测量，无物体任务、接触力、连续碰撞或实机证明；四臂全部操作空间尚未覆盖。旧连续cell计数保留，未定位隐藏重置状态，只通过独立启动隔离该影响。
