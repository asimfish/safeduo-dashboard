# 扩大随机操作空间：预登记

用户要求随机性更强、覆盖范围更大。目标是扩展实际初态/轨迹覆盖并暴露安全失败；不是增加重复窗口制造安全率。上一轮seed12的事后停止诊断不作本轮检测器，也不加入本轮预防成功率。

固定 actor a31b、pending_guard、critical-only 10mm/容量128（actor仍32行）、backlog_aware=false、物理参数。生产安全源码和权重不改。三个新登记种子731923/2048171/9987031，三个分布×两个方法raw/System 0，每条件64环境、15秒、6步严格FIFO，18个新进程、1152相关窗口（每方法576）。无逐失败轨迹选定停止触发。

分布：

1. wide_iid：默认q附近每关节独立均匀±1.2rad，软限位裁剪并记录；每步26关节独立均匀±0.05rad纯随机指令。
2. wide_burst：同种子与wide_iid完全相同的初态；每环境、每臂独立随机选择保持1/4/15/30/90/180控制步，段内各关节独立均匀方向，幅度档独立随机0.005/0.015/0.025/0.05rad/步。手指固定，不是假称全部手部随机。
3. global_burst：每关节软限位归一化[0.025,0.975]（95%跨度），随机Latin hypercube分层，独立维度排列和层内随机；四臂全部26受控关节采样，同wide_burst指令分布。分层边际覆盖不等于26维笛卡尔积或EE可达体积均匀，也不是pure IID初态。

所有命令为预生成、与状态无关的纯随机tape；三个独立CPU随机流分别控制方向、换向时间、幅度档，初态另用独立种子。raw/System 0逐位核验全部初态与命令。初态碰撞不拒绝、样本不筛选，分别展示全部初态违规、无违规初态后的失败、已有重叠的后续加重。系统可能直接产生无效cell或容量溢出：保留协议、初态快照、错误日志，不能算安全窗口；注册驱动允许独立cell失败后继续剩余条件，源/权重漂移则立即中止，人工中断不会继续。

低磁盘环境，原始NPZ放NAS新目录；使用紧凑轨迹记录q/qdot/实际发送与送达目标/EE/六对球距/官方四通道，不保留本轮不需要的巨大Jacobian。EE位置已由scene_state减去各env原点，禁止用环境平铺坐标虚构范围。

预定覆盖审计：26关节初态及实际访问的10个归一化区间（越界另列，不裁剪成覆盖）；全体与无违规初态子集分别记录；每臂局部EE的10cm格子并集（只计访问格，不用包围盒体积假称全域）；六组臂对至少3步进入80mm、进入5mm以及相对靠近/远离/切向步数；完整随机tape的指令幅度、换向/档位计数、四臂同时激活和指令/实际运动差异。单关节边际覆盖、指令熵、格子数和实际运动量均不单独证明足够安全。

契约验证：随机源同种子逐位复现、不同种子不同、四臂异步换向、换向间隔/幅度档、IID每步更新、独立状态无关tape、每维分层覆盖、软限位和裁剪记录；真实子进程失败继续并保留未完成状态，源/actor漂移中止。仿真每条件独立启动，实际FIFO逐位核对。先保存缺失新功能的RED，再实现并检查GREEN。

不得把raw与System 0相关配对、global分层样本、已有初态重叠或时间步视为IID独立安全样本。不提供本轮独立安全置信界。物体任务、随机手指、传感/质量/摩擦、接触力、连续碰撞、实机和全部四臂可达空间仍需独立实验。
