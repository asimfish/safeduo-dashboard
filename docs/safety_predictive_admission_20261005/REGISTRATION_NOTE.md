# 登记谱系说明

本轮candidate/holdout登记继承旧campaign的源文件hash与字段，作为已冻结执行器、actor和原随机协议的谱系。旧device_note/continuation_reason/prior_campaign_path说明的是历史步骤，不能解释为本轮设备条件或本轮已经失败/重跑。当前条件以本轮jobs.argv、expected_args及每个完整protocol.args为准：开发cuda:1，新留出全部cuda:0；每个条件新进程，CUDA_VISIBLE_DEVICES=0,1避免重映射。当前本轮source/actor/config与同输入/FIFO逐条件核验，原登记文件不作事后文字重写。

PLAN.md的契约例子使用80mm、0.5m/s、cross0.16s，完整有效dmin20mm+10mm：预测0mm必须入选，静态80mm在该band外。前面的“40mm/s?”是说明稿残留，不是实验参数或任何实际代码值；注册哈希及原文保留。
