# 同设备重复验证

仅速度盒三个条件在GPU1已结束、最终分析尚未读取之前，登记GPU1配套raw及原System0六个条件。已有主压力部分结果可见，原速度盒结果未用于选择条件；全部三个种子原样重复，无调参、初态重筛或删失败。384重复窗口，0新增独立输入；与已有192仅限速窗口形成GPU1三方法576相关窗口，不混入主960或零输入576分母。

调用原mechanism_runner.py、baseline/raw模式；原投影、模型、配置、actor32、动态512、软目标限位、积分目标、严格FIFO6保持。三方法共享物理设备cuda:1、新进程。全部960帧、输入/初态hash、目标FIFO和安全判据保持。安全与首次违规前/全窗操作范围并列，三种子配对两种比较共6行，包含新增失败。

原analyze_speed.py的主GPU0与补充GPU1配对保留为审计描述；面板主要补充结论使用本次同GPU1三方法重放。跨GPU的实际轨迹不能假定逐位相同；同初态和外部指令逐位一致不要求保护后实际轨迹相同。同设备重复验证仍非实机保证。
