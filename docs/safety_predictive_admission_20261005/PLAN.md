# 完整速度预测入选：冻结机制因子与新留出

目标：在严格六步FIFO、原actor32行、原PD/物理和投影参数下，检验完整身体速度的预测关键行入选能否减少碰撞，并保留实际关节运动范围。核心生产文件不修改，不推广本评测候选。

证据：旧60317411开发重播baseline首次分类事件58个、37个出现预测关键帧未入选；envelope事件9个、6个有此现象。非入选行速度来自观察后的有限差分，明确含hindsight；仅指导假设，不计闭环验证。旧trace完整身体速度与目标退开仍闭合、共同线性不可行现象也保留，不能把入选认定为唯一原因。

冻结预测：在线读取当前完整9021球距与完整实际身体速度（full.closing），cross0.16s/self0.40s/table0.30s，与已有冻结类预测时间相同。入选条件 distance - horizon*max(closing,0) <= current_full_dmin+10mm；保留所有旧top32/瞬时关键union行。仅增加入选，不改变cap计算、结构/接触豁免、alpha、authority clamp、solver或FIFO。所有table类用于入选0.30s（包括原投影永久结构行），投影仍按原永久结构语义处理。无需future commands或反馈随机输入。动态精确宽度、预算2048；超限中止并计无效，不截断、不冒称安全。

五方法：raw、baseline（原dynamic512）、envelope_050（旧固定±0.050rad候选）、predictive（只改预测入选）、predictive_envelope（两个因子）。predictive沿用原R19等全部输出行为，可能超过0.025rad；envelope两方法必须通过原增量/软限位/独立解析包络oracle。本实验故意不同时修复其他机制，避免混淆因子。

开发：只使用旧60317411，同输入64窗口，各新predictive方法独立进程cuda:1，共128重复窗口、0新指令；baseline/envelope旧实测作为明确复用对照。不修改已冻结参数或因开发结果取消/替换预定条件。

独立留出：新种子331047829/389116237/451902773；每种子六组臂对各8初始20–60mm风险姿态、16广域稳定姿态，共192初态/外部指令组。沿用原风险采样/一秒raw零输入资格，仅依初始几何与静置结果首个合格顺序，候选/拒绝及选择引用全部保存于NAS，不依随机保护表现挑样。general95%软限位跨度LHS，风险目标两臂95%跨度、其他臂基姿±0.3rad；不声称26维穷尽覆盖。

每方法每种子64环境16秒960控制步，新OS进程cuda:0，五方法同q0和全部tape；60零输入+900压力，四臂独立方向/异步保持1/4/15/30/90/180步，幅度0.005/0.015/0.025/0.05rad，与旧随机协议相同。全窗计失败，保留深穿透>5mm与四类、零前缀、初态引用、真实FIFO、实际目标软限位、真实增量、四臂活动量、L2输出、关节边际/末端格和路径、逐臂对真实压力。15cells960配对窗口；不将192组指令说成960条独立轨迹，不给IID总体置信界。
