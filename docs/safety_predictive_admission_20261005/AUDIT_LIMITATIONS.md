# 离线入选时机审计的限制

admission_audit.py在旧开发trace的已入选行使用精确pre_row_full_rate与当帧有效dmin；缺失行只能用实际前后状态有限差分估计速度，并使用名义dmin。缺失条件接触行当帧有效dmin没有保存，名义值可能比豁免值大。coarse_capacity_estimate亦使用名义dmin与后续有限差分，只是开发预算粗估，可能高估，不是线上容量证据。

37/58与6/9是该离线估计下的事件数，不能断言这些缺失行在当前完整有效dmin/瞬时速度下必然应入选，也不能声称入选是唯一根因或部署预测保证。所有原始数据、脚本和hash保持，限制另列，不修饰原结果。

新运行predictive_rows.py使用真实当帧完整d、完整closing与完整有效dmin，保留接触豁免；新入选契约及实际运行计数独立于离线有限差分。2048容量若超限会中止、保留无效，不因离线预算估计而保证完成。
