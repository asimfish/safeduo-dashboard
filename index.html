            10 维护契约（人 + 多 agent）

            • 服务器快照（runs.json：bjxy_5090 每卡显存/利用率/进程标签、tmux、训练 run 末行统计、四门目录进度）由 Mac 端 update_dashboard.sh（launchd，每 10 分钟）通过 ssh 运行 collect_remote.py 采集，推送到 data 分支；Mac 休眠或服务器不可达时停更并标红。
            • 四门矩阵：gates.json 由 build_gates.py 从远端 ~/safeduo/artifacts/clutch/*/cell_*.json 镜像自动生成，禁止手改数字；plan.json 是计划网格（策略 × 执行栈 × θ），新增实验先写进 plan.json 再发车；build_matrix.py 合成 matrix.json。
            • 内容快照（status.json：目标、焦点、决策、判决、队列、文献、日志；roadmap.json：R 行；tasks.json：任务族/资产/R34）由 agent 在里程碑手工更新——每条判决必须带证据路径，与 safeduo/paper/MASTER_REPORT.html（活文档，实验线维护）一致；面板不替代 MASTER，只做索引与看板。
            • 分工：实验线（原 safeduo_实验 会话）= 训练/四门/录制与 MASTER §9/§10；设计线（本面板维护者）= 方案设计、总结、文献、面板与仓库。两线不同时改同一文件：设计线只加新文件（docs/、task_library_r34.py、assets_src/tasks/r34/）。
            • 编码红线：含中文文件一律 shell heredoc 写入并 file --mime-encoding 验证（本机编辑器 Write 工具会损坏非 ASCII）。
            • 安全红线：远程服务器不 kill 他人进程；GPU 探针只在空档跑；训练/评测 yaml 默认值改动须经 owner。
