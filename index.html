                维护契约（人 + 多 agent）

                • 服务器快照（runs.json）与视频库（safeduo-media/index.json）由 Mac 端 update_dashboard.sh（launchd，每 10 分钟）采集、转码、推送；Mac 休眠或服务器不可达时停更并标红。
                • 四门矩阵：gates.json 由 build_gates.py 从远端 artifacts/clutch/*/cell_*.json 自动生成，禁止手改数字；新增实验先写进 plan.json 再发车；build_matrix.py 合成计划 vs 完成。
                • 内容快照（status.json：两条线动态、目标、焦点、决策、判决、队列、文献、日志；roadmap.json；tasks.json）由 agent 在里程碑手工更新；每条判决必须带证据路径，与 safeduo/paper/MASTER_REPORT.html（活文档，实验线维护）一致。面板不替代 MASTER，只做索引与看板。
                • 算法设计（algorithm.json + diagrams/algorithm_vN.svg + docs/ALGORITHM_DESIGN.md）：训练配方、网络、执行语义、代价/乘子任何改动都必须同步这三处并写入算法变更日志（版本号 +1）；参考设计对照表记录采纳/不采纳及理由。
                • 分工：实验线（原 safeduo_实验 会话）= 训练 / 四门 / 录制 / MASTER；设计线（本面板维护者）= 方案、总结、文献、面板、仓库、工业资产。两线不同时改同一文件；设计线只加新文件。
                • 编码红线：含中文文件一律 shell heredoc 写入并 file --mime-encoding 验证。安全红线：远程服务器不 kill 他人进程；GPU 探针看空档；训练/评测 yaml 默认值改动须经 owner。
