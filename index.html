                  • 算法设计（algorithm.json + diagrams/algorithm_vN.svg + docs/ALGORITHM_DESIGN.md）：训练配方、网络、执行语义、代价/乘子任何改动都必须同步这三处并写入算法变更日志（版本号 +1）；参考设计对照表记录采纳/不采纳及理由。
                  • 分工：实验线（原 safeduo_实验 会话）= 训练 / 四门 / 录制 / MASTER；设计线（本面板维护者）= 方案、总结、文献、面板、仓库、工业资产。两线不同时改同一文件；设计线只加新文件。
                  • 编码红线：含中文文件一律 shell heredoc 写入并 file --mime-encoding 验证。安全红线：远程服务器不 kill 他人进程；GPU 探针看空档；训练/评测 yaml 默认值改动须经 owner。
