# Frozen collector retry contract

The final run `fresh_scene_batch` repeats exactly the 24 reference frames, 12 selected hand goals, physical gains, 8640 physics steps, camera capture clocks and safety thresholds frozen in `REGISTRATION_FRESH_SCENE.json`. It does not add independent contexts. The unchanged controller and geometry source files remain hash-bound. The collector batches native contact queries into six views; sensor/partner identities, local point capacity (4096), point tuples and state epoch semantics remain unchanged. Global native forces/counts/start offsets are archived alongside locally packed records.

Activation requires a complete 720-step known-contact pilot, with an independent mapping audit and full-path scorer. A known-contact baseline is expected to fail the scientific safety criterion; its exact target reconstruction, native point reconstruction, recovery behavior and source closure must pass. An initialization failure, missing receipt, or a zero Kit exit code alone cannot pass this gate.

Incomplete attempts retain all emitted chunks, screenshots and logs. They are not pooled into the complete-run sample count or reported as qualification. No safety thresholds or goals may be tuned using the frozen 24-frame bank. The same-frame batch-query timing experiment is a microbenchmark, not an end-to-end speed claim.
