# Delivery verification contract

The claim is limited empty-hand admission safety at the frozen static four-arm configurations, never full System0/manipulation acceptance. A failed scientific result must still be delivered accurately.

Required terminal evidence:
1. Every planned native step, image and chunk has a complete receipt; all point tuples, identities, render invariance, control targets and source hashes pass independent reconstruction. Failed/incomplete attempts remain published separately.
2. The batch collector pilot preserves global/native-to-local mapping and reproduces two known unsafe baseline contacts with latched recovery. Fresh mapping is audited over every archived frame.
3. Per-method counts distinguish moving execution, neutral targets, refusals and aborts. Limited candidate pass requires nonzero moving execution, every admitted path qualified, every refusal neutral-safe and no aborts. Old baseline failures are expected negative controls.
4. Source snapshot and registered runtime/criteria are byte-identical to source seals. Native asset/material dependency closure remains explicitly incomplete; no formal global safety claim.
5. JavaScript syntax checks, desktop/mobile local browser and public browser: all curves, 256 final-phase images and six actual decoded videos, no JavaScript error or horizontal overflow. Reconstructed videos are explicitly marked.
6. Main root old evidence card is preserved byte-for-byte outside the new section; main payload remains under 1 GiB; no credential patterns or >100 MiB archive blobs.
7. Explicit Git diff/staging review, immutable archive commit and full public byte/SHA download; Pages workflow success at exact main commit, exact public main files and browser evidence.

No end-to-end performance improvement is claimed from the same-frame query benchmark. Performance stage verifies only its parity/timing microbenchmark scope. Constructor contacts, true grasp/load release, whole-arm trajectories, arbitrary hand vectors and dynamic obstacles remain unqualified.
