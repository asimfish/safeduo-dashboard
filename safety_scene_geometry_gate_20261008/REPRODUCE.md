Run SOFTWARE_CONTRACT_TEST.log command with the SafeDuo Python environment and isolated runtime PYTHONPATH. diagnose_archive_v2.py needs standalone omni.usd.libs Python/library paths; its offline FR3 remote-resolution warnings are preserved and its result is a U-hand FK / fixture diagnostic.

Native command: CUDA_VISIBLE_DEVICES=0,1 PYTHONPATH=<this>/runtime:/home/liyufeng/safeduo/src LD_PRELOAD=/home/liyufeng/miniforge3/envs/safeduo/lib/libstdc++.so.6 OMNI_KIT_ACCEPT_EULA=YES PRIVACY_CONSENT=Y OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 PYTHONUNBUFFERED=1 PYTHONDONTWRITEBYTECODE=1 /home/liyufeng/miniforge3/envs/safeduo/bin/python <this>/runtime/native_scene.py --registration <this>/REGISTRATION_<RUN>.json --out <NEW-output> --headless --device cuda:0 --kit_args '--/renderer/activeGpu=0 --/renderer/multiGpu/enabled=false'

Never overwrite a registered file/output; reruns need a new output directory. A zero Kit process exit is insufficient: require complete recording receipt, no failure.txt, all SHA-256 checks, matching contact identities and independent analyze_scene.py measurement. analyze_scene.py --name matched_scene or fresh_scene_batch verifies original scalar contact points and all six-second phases; it imports no admission controller or geometry predictor. Denials are scored as neutral holds, not successful closure/grasp. Initial arm targets are constant, actual motor-held arm motion is measured separately.

Geometry extracted from the actual native stage is stored in geometry_schema.json. All enabled robot/scene colliders must be inventoried. The outer boxes contain actual mesh/primitive geometry; stale authored extent is ignored. Geometry predictions are conservative with engineering reserves, not formally calibrated reachable tubes. Moving obstacles, loaded hands, intended object contacts, image-derived perception and whole-arm trajectories are not qualified by this experiment. Constructor warmstart contacts remain unmeasured. Used simulator dependency/material versions are not fully sealed by Python/runtime hashes. Scope does not establish IID task risk or full 26-DOF reachable-volume coverage.

Three video clips are direct native captures, state-invariance checked around each render. Three supplementary overhead clips reconstruct archived native states without taking physics steps; they are explicitly labelled and add zero safety trials. Previous rejected V3 and the first rejected extent-based offline diagnostic remain available. All outcomes, refusals and failures must be published.

Batch collector: use runtime_batch/native_scene_batch.py with PYTHONPATH=<this>/runtime_batch:<this>/runtime:<source>, and the same complete launch environment above. --kit_args must be one argument (for example --kit_args="--/renderer/activeGpu=0 --/renderer/multiGpu/enabled=false"). Before fresh_scene_batch, require batch_pilot_ready complete 720-step receipt, analyze_scene.py data/target/source assertions, and audit_batch_mapping.py --name batch_pilot_ready. After the fresh run, run both independent auditors again. Batch identity maps and original global native force/count/start arrays are archived.

The fresh_scene and fresh_scene_retry folders are incomplete attempts, retained without pooling. batch_pilot failed native initialization; batch_pilot_retry stopped after launch environment errors. Logs of bootstrap/CLI attempts are retained. The final retry uses the same 24 frozen contexts and does not contribute a new independent bank.
